- **Dependências:** M1 · **Status:** ⬜ Não iniciado · **Fechado em:** —

## Checklist de atividades (ordem TDD)
- [ ] Registry de backend por catálogo (`model_id → backend`) via Protocol `InferenceBackend`.
- [ ] `OllamaBackend`: `/api/chat` com stream (permite checagem de cancelamento por chunk).
- [ ] Worker Celery: prefetch=1, `acks_late=True`.
- [ ] Timeout com `Clock` injetável → abort + `failed(code=timeout)` + libera slot.
- [ ] Classificador de erros por backend (`retryable: bool`).
- [ ] Retry transiente com backoff 1s/4s/16s até 3 tentativas.
- [ ] Registro de `usage` (tokens in/out, duration_ms, backend, attempt).
- [ ] Transições `queued→running→succeeded|failed` com `job_events`.
- [ ] Crash-recovery: redelivery via `acks_late`, reprocesso com `attempt+1`.
