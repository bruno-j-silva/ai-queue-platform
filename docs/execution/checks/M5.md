# Check — M5 · Cancelamento de jobs

- **Fase:** F5 · **Spec:** [SPEC-004](../../specs/SPEC-004-cancellation.md) · **Requisitos:** RF-030..032 · **ADRs:** ADR-005
- **Dependências:** M2 (paralelo a M3/M4) · **Status:** ⬜ Não iniciado · **Fechado em:** —

## Checklist de atividades (ordem TDD)
- [ ] `DELETE /v1/jobs/{id}` → 202 (queued/running) · 409 (terminal) · 404 (cross-tenant).
- [ ] Flag `cancel_requested` em Postgres + cache Redis TTL curto.
- [ ] Queued: tombstone — worker descarta ao consumir → `cancelled` sem inferência.
- [ ] Running: CancelToken checado a cada chunk / ≤ 2s → `backend.abort()` → `cancelled` ≤ 10s.
- [ ] Compare-and-swap no status terminal (corrida cancel × término, único vencedor).
- [ ] Supressão de webhook `succeeded/failed`; emitir só `job.cancelled`.
- [ ] `job_events` com origem `api_cancel`; liberação imediata do worker.
