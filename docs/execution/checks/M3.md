# Check — M3 · Entrega por webhook

- **Fase:** F3 · **Spec:** [SPEC-003](../../specs/SPEC-003-webhook-delivery.md) · **Requisitos:** RF-040..044, RB-04 · **ADRs:** ADR-006
- **Dependências:** M2 (paralelo a M4/M5) · **Status:** ⬜ Não iniciado · **Fechado em:** —

## Checklist de atividades (ordem TDD)
- [ ] CRUD `webhook_endpoints`; segredo gerado no create, exibido uma vez, hasheado/cifrado.
- [ ] Assinatura HMAC-SHA256 de `timestamp + "." + body` (função pura + verificação de adulteração).
- [ ] Criação de `webhook_delivery` na mesma tx da transição terminal + publish pelo relay.
- [ ] Dispatcher Celery: POST timeout 10s, headers `X-Delivery-Id/Timestamp/Attempt/Signature`.
- [ ] Backoff 1m/5m/30m/2h/12h + jitter ±20% via `next_attempt_at` + poller (Clock injetável).
- [ ] Esgotamento → `dead` + `webhooks.dlq` + métrica `webhook_dead_total`.
- [ ] Redeliver admin preservando `delivery_id`, `attempt` incrementado.
- [ ] `POST /v1/webhook-endpoints/{id}/test` (evento de teste).
